 Sales Data Analysis Using Python and Pandas

 1. Project Overview
This project analyzes a sample sales dataset using Python and Pandas. It calculates total revenue, average order value, and best-selling products, and summarizes sales by category, region, and month.


 2. Technologies Used
- Python
- Pandas
- Google Colab
- GitHub

3. Setup Instructions

Requirements
- A Google account
- Internet connection
- A web browser

 Steps to Run
1. Download the `CodeOrbit_Sales_Analysis.ipynb` notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Click File → Upload notebook.
4. Select the downloaded `.ipynb` file.
5. Run the code cells from top to bottom to view the analysis and results.
6. Report stored on Sales Data Analysis Using Pandas.docx
 4. Key Findings
- Total Revenue: ₹1,880
- Average Order Value: ₹313.33
- Best-Selling Product: Pen (8 units sold)
- Top Revenue Category: Accessories (₹1,500)
- Top Revenue Region: East (₹1,500)
- Top Revenue Month: March (₹1,200)

These results are based on the sample practice dataset included in the notebook.
